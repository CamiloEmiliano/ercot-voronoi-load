# Project notes

This project is intentionally simple but structured like a serious portfolio artifact.

## Goals

- model demand with uncertainty
- incorporate trend and seasonality
- include a promotion effect
- produce a forecast with credible intervals

## Planned extensions

1. Add a proper holdout validation design.
2. Compare against a baseline model.
3. Add store or product hierarchies.
4. Use real demand data instead of synthetic data.
5. Add a Streamlit dashboard.
